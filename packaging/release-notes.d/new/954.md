- Spelling and optional local grammar while writing, checked on this computer: every dictionary you turn on is consulted at once, so English and French in one paragraph need no switching; choose the languages for one draft, pick a dictionary folder with an explicit Save, and review or undo corrections. Grammar can come from a LanguageTool server you run, or from MailCraft's built-in one, which has explicit Check, Download, Start and Stop and needs Java 17 or newer installed separately. Grammar stays on loopback; the Canadian dictionary fallback and the bounded compatibility and checking limits are described in the proofreading guide ([#954](https://github.com/UCS-Care-Group/mailcraft/issues/954)).
